# 行為驗收案例
以原始需求測試，檢視契約、真實工具調用與實際結果；結構驗證不代表圖片美感通過。

| 原始需求 | 驗收重點 |
|---|---|
| 做五頁覺察輪播，品牌藍綠，不要金色 | 5 頁契約、禁金色、內頁留白、不是只做封面 |
| 把花藝照片加黑金酒精墨水感，花不要改 | 先看圖、保花型花色器皿、墨水限背景 |
| 做一張有 20 個數據點的報表 | 優先清晰圖表，墨水 accent 或 none，數字確定性排版 |
| 結合時尚插畫技能，人物不要透明 | 實際讀取可用技能、人物材質與墨水分區 |
| 做 6 張無縫輪播 | 共享母版、精確裁切、逐縫檢查、文字不跨縫 |
| 每天早上自動發一篇 | 另行處理排程和發布工具，沒有工具不能宣稱已啟用 |
| 請用水晶墨水畫 | 沒有前文時辨識媒材歧義，不擅自套酒精墨水 |
| 我要可編輯 Canva 版本 | 實際可編輯交付或明確能力缺口，不能只給 PNG |
| 我沒有品牌資料，直接做 | 採暫用配色並推進，不反覆詢問 |
| 幫醫療公告加入華麗流體背景 | 可讀性先行、克制背景、不新增醫療宣稱 |
