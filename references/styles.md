# 風格庫與路由
以下是內部視覺分類，不是藝術史上的官方流派。數值是設計起點，非材料物理量。

| ID | 視覺語法 | 適用 | 避免 |
|---|---|---|---|
| silk-mist | 半透明薄膜、羽化流邊、輕盈重疊，局部沉積邊 | 覺察、關係、優雅品牌 | 全幅模糊、塑膠皺褶 |
| mineral-vein | 深淺色帶、礦脈交界、少量金屬沉積 | 精品、工藝、作品展示 | 遍布金粉、假立體珠寶 |
| organic-bloom | 放射花瓣、有機暈染、局部筆線 | 花藝、生活、自然 | 無主次的花團、覆蓋商品 |
| coastal-flow | 水平色流、海岸過渡、疏密浪線 | 旅遊、自然、舒展 | 無需求的擬真海浪 |
| mountain-haze | 分層墨脊、低彩度霧帶、遠近留白 | 東方美感、沉靜敘事 | 假書法、亂造文化符號 |
| vivid-current | 兩至三主色、大幅色流、集中對比 | 活動、創意、突破 | 彩虹堆疊、文字區撞色 |
| quiet-space | 單色或雙色、邊緣少量暈染、大片安靜底 | 知識、顧問、長文輪播 | 把留白填滿 |
| nocturne-metal | 深底透明墨層、低亮金屬細脈 | 暗黑攝影、成熟品牌 | 暗部糊死、金色遮臉 |

路由步驟：
1. 以使用者指定風格為第一候選，先檢查硬限制。
2. 以品牌相容、可讀性、主題適配、一致性、成本各給 0–2 分作內部比較；不是成效預測。
3. 可讀性為 0 時改為局部點綴或安靜底；不可用總分抵銷硬限制。
4. 無明確藝術需求時，知識內容採 quiet-space，人物內容採 silk-mist accent，作品展示採 mineral-vein accent；缺乏足夠資訊時採 quiet-space。
5. 輔風格僅限相容材質：silk-mist+organic-bloom、mineral-vein+nocturne-metal、coastal-flow+quiet-space。其他組合須有可解釋的分區。

參數：ink_strength 0–1；texture_density 0–1；metallic_ratio 0–0.15；negative_space 0.2–0.8。教學頁建議 negative_space≥0.55、ink_strength≤0.25，文字放獨立安靜面板。這些是設計目標，須以實際圖片檢查，不能聲稱精準測量。
保留酒精墨水辨識：透明染料層、流動分叉、乾燥沉積邊、局部色素聚集。避免把它全面替換成水彩紙紋、厚重油彩或樹脂流體。
