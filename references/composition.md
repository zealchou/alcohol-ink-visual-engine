# 跨技能分工

| 角色 | 權責 | 交接內容 |
|---|---|---|
| 主控 | 內容目的、範圍、交付與執行順序 | 任務契約、每頁內容 |
| 品牌 | 配色、Logo、字體、禁用元素 | brand、visual_lock |
| 本引擎 | 墨水色層、流動、沉積邊與作用區域 | style、regions.ink |
| 攝影 | 身分、產品形狀、打光、景深 | preserve、regions.subject |
| 時尚插畫 | 人體比例、服裝、線條及面料 | 主體區、固定參考 |
| 輪播排版 | 格線、字級、順序、接縫、CTA | pages、regions.text |
| 生圖工具 | 按組合提示詞生成或修改素材 | prompt、參考素材 |
| 檢查 | 按實際結果驗收 | 圖片、契約、問題清單 |

若可用，搜尋 atelier-art-photography／藝作光影質感引擎、garytus-fashion-engine、輪播模板相關 Skill 的真實名稱與說明，再讀取；別只因名稱相似就宣稱已整合。
選最多兩個主動視覺技能加排版與品牌規則。先鎖主體，再加入墨水，最後排字；不讓每個技能輪流重畫已鎖定主體。
混合範例：
- 花藝作品：攝影維持花型、花色和器皿；organic-bloom 僅在背景呼應，不新增讓顧客誤認為作品內容的花。
- 顧問人像：攝影保留人物；nocturne-metal 只在遠離臉部的背景使用細脈。
- 時尚插畫：插畫管理姿態與面料；silk-mist 管周邊氣流，避免把皮革也變成透明墨水。
- 數據輪播：圖表確定性製作；quiet-space 只在邊角，不讓墨水紋理暗示不存在的數據。
若工具無圖層遮罩能力，先生成背景再合成主體；仍無法保真時不要聲稱完成精確保留。

同一請求同時指定黑金與品牌禁金、或同時要求保留與改變同一主體時，先提出一個合併釐清問題。答案前可先完成不依賴衝突部分的規劃；不要把模糊矛盾擅自視為已授權品牌例外。
