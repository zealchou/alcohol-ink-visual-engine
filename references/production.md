# 生成與版型

## 提示詞組裝
按序填寫：用途與比例 → 主風格材質 → 主體與位置 → 品牌配色 → 色流與密度 → 文字安靜區 → 保留約束 → 禁用元素 → 參考圖用途。

可重用模板：
「為 {purpose} 製作 {ratio} 數位視覺。模擬酒精墨水在光滑非吸水表面的透明染料薄層、自然分叉與局部乾燥沉積邊。採 {primary}，{palette} 配色，{flow} 色流，{strength} 強度。主體在 {subject_region}，保持 {preserve}。{text_region} 保留平靜、均勻、低紋理留白以供後續排字。墨水只作用 {ink_region}。避免 {forbidden}。不生成文字、Logo 或假簽名。」
英語材質補充可用 translucent dye veils, feathered blooms, pigment pooling, fine tide lines, restrained metallic pigment；不得只堆砌 luxury、8K 等空泛字詞。

## 輪播
- 封面建立主視覺，內頁降低紋理，結尾保留 CTA 區；沿用同一配色、字體和色流邏輯。
- 整組先規劃每頁文字量與區域。不得為了全部塞入而縮成手機難讀小字。
- 無縫背景採 W=N×page_width、H=page_height 的長幅母版，依確定座標裁切。工具不支援長幅時製作共享背景或確定性平面漸層，再疊墨水素材；不得保證分開生成可以自然接縫。
- 跨頁只讓背景銜接；臉、Logo、主要標題不跨切線。
- scripts/crop_carousel.py 僅裁背景；文字與頁碼在裁切後逐頁排版。

## 輸出
常用設計起點：直式 1080×1350、正方 1080×1080、故事型 1080×1920、橫式 1920×1080。僅為預設，不是平台現行規格聲明；用戶要求最新限制時另查官方文件。
使用 PNG 保存透明度或清晰圖文，JPEG 用於不需透明的照片；印刷、CMYK、出血與金屬特效須依印刷廠規格另處理。
實際有影像工具時才生成。需放大或精確重採樣時標示過程，勿將放大稱為原生解析度。
