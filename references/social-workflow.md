# 自媒體批次流程

接收選題／已確認文案 → 建立每篇契約 → 選風格與角色 → 鎖定品牌與整組母版 → 調用實際可用技能 → 產出素材 → 排字 → 檢查 → 交付 → 依另行授權發布。

批次以品牌為隔離單位；先檢查 1 組母版再擴充剩餘內容。使用者要求全數完成時持續完成，不以一張示意圖取代整批。
可讀取既有內容日曆，但修改日期或發布狀態需符合任務授權。工具不可用時交接契約與明確待辦，不虛構已連接平台。
以 task_id 關聯成品；重跑時檢查既有輸出，避免重複發布。發布介面可用時也需確認帳號、內容與排程時區。
僅當使用者要求，使用排程工具建立未來任務；安裝本 Skill 本身不等於建立排程。
回饋記錄建議：內容類別、使用風格、人工修改、可讀性問題、製作時間、生成次數、實際成效及統計期間。以有資料的比較調整預設，不將點擊差異直接歸因於墨水風格。
成本控制：先選定方向後生成；重用母版；針對缺陷局部編輯；尊重明示預算；不擅自開通訂閱或購買工具。
