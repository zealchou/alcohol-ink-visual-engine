# 流光墨韻｜酒精墨水視覺引擎

完整可安裝 Skill，提供八種酒精墨水數位風格、自媒體路由、品牌限制、跨技能交接、輪播一致性與品質檢查。

入口：[SKILL.md](SKILL.md)。將整個資料夾作為一個 Skill 匯入支援的環境；本備份不會自行安裝依賴或建立社群發布服務。

使用：`使用 $alcohol-ink-visual-engine，依我的文案與品牌，自動選風格並完成整組輪播。`

## 檔案

- `references/`：風格庫、共用契約、技能分工、製作、品質、自媒體流程與驗收案例。
- `scripts/validate_contract.py`：檢查 JSON 製作契約，使用 Python 3。
- `scripts/crop_carousel.py`：以精確像素裁切共享背景，需 Pillow；不自動放大、不覆寫既有輸出。

## 能力界線

圖片是酒精墨水質感的數位模擬。實際生圖、可編輯排版、排程與發布需所在環境具備相應工具。此版本已通過結構、契約、裁切與文字情境驗證，尚未完成實際生圖美感驗收及社群發布端到端測試。
